How It Works

  1. Scraping — The extension opens Remote.co category pages in background tabs and extracts job listings from the DOM. You can also use the floating "Scrape Jobs" button when browsing Remote.co manually.
  2. Local NLP — Jobs are instantly classified by industry, experience level, and location type using keyword-based pattern matching.
  3. AI Enhancement — Optionally run AI classification via GitHub Models for more accurate title normalization and industry/experience mapping.
  4. Export — Download your classified and deduplicated jobs as JSON or CSV for analysis, database import, or further processing.

Supported Categories

The extension supports 40+ Remote.co job categories including:

Developer, Software Engineer, IT, Marketing, Healthcare, Sales, Design, QA, Customer Service, Operations, Writing, HR, Finance, Legal, Education, Engineering, and many more.
